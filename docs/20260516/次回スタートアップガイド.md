## 🔧 トラブルシューティング

### 問題1: シミュレータが起動しない

**症状**: `i` キーを押してもシミュレータが起動しない

**解決策**:
```bash
# Xcodeを開いてシミュレータを手動起動
open -a Simulator

# または特定のシミュレータを指定
xcrun simctl boot "iPhone 15 Pro"
```

---

### 問題2: メトロバンドラーがエラーで止まる

**症状**: `ERROR: Unable to resolve module`

**解決策**:
```bash
# キャッシュをクリア
npx expo start --clear

# または node_modules を再インストール
rm -rf node_modules
npm install
```

---

### 問題3: 「no such table」エラー

**症状**: オンボーディング完了時に DB エラー

**解決策**:
1. **アプリをアンインストール**
   ```bash
   xcrun simctl uninstall booted app.pilllog.tasukuh
   ```

2. **マイグレーションログを確認**
   - ターミナルで `[DB] ✓ Statement X executed successfully` が10個出ているか
   - 出ていない場合は `lib/db/index.ts` を確認

3. **DBファイルを直接削除（最終手段）**
   ```bash
   # シミュレータのデータディレクトリを探す
   xcrun simctl get_app_container booted app.pilllog.tasukuh data
   # 出力されたパスに移動して pilllog.db を削除
   ```

---

### 問題4: TypeScript エラーが出る

**症状**: ファイル保存時に赤い波線

**解決策**:
```bash
# TypeScript エラーを確認
npx tsc --noEmit

# 主なエラーパターン:
# - 'id' が存在しない → プロパティ追加
# - 型が合わない → as で型アサーション
# - import が解決できない → パスエイリアス確認
```

---

### 問題5: ホーム画面が真っ白

**症状**: オンボーディング後にホーム画面が表示されない

**確認事項**:
1. **ログを確認**
   - `[DB] Initialization complete` が出ているか
   - エラーログがないか

2. **データが存在するか確認**
   ```typescript
   // app/(tabs)/index.tsx の先頭に追加

   console.log('todaysDose:', todaysDose);
   ```
