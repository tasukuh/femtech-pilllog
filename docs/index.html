ピルログ

シンプルなピル管理

ピルログは、服薬記録を簡単に管理できるアプリです。
通知リマインダーで飲み忘れを防ぎ、履歴で服薬状況を一目で確認できます。

📝 簡単記録

ワンタップで服薬を記録。ロック画面からも直接記録可能。

🔔 通知リマインダー

設定した時刻に通知でお知らせ。段階的なリマインダーで飲み忘れを防止。

📊 履歴管理

カレンダーで服薬履歴を一目で確認。統計で達成率も表示。

🔒 完全プライベート

すべてのデータはあなたのデバイス内にのみ保存。サーバーには送信されません。
