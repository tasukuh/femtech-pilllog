### Bug 1: カレンダーで月をまたぐと誤ってペイウォールが発動する

#### 症状

- 今日が 6 月 3 日の場合、過去 7 日 = 5 月 27 日〜6 月 3 日が閲覧可能なはず
- 「前の月（5 月）」ボタンを押すと「7 日以上前の履歴を見るにはアップグレードが必要です」が表示され、5 月に戻れない

#### 根本原因

`history.tsx` の月移動ロジックで、移動先の月の「**開始日**」を 7 日前と比較していた。

```
// 修正前（誤り）
const newMonthStart = startOfMonth(newMonth);   // 5 月 → 5 月 1 日
if (isBefore(newMonthStart, sevenDaysAgo)) {   // 5/1 < 5/27 → ペイウォール発動 ❌
```

5 月 27〜31 日は 7 日以内に含まれるにもかかわらず、月の開始日（5/1）で判定していたため誤発動していた。

#### 修正内容

比較対象を月の開始日から**終了日**に変更。月内に 1 日でも 7 日以内の日付があれば閲覧を許可する。

```
// 修正後（正しい）
const newMonthEnd = endOfMonth(newMonth);       // 5 月 → 5 月 31 日
if (isBefore(newMonthEnd, sevenDaysAgo)) {      // 5/31 > 5/27 → 通過 ✅
```

**変更ファイル**: `app/(tabs)/history.tsx:108`

### Bug 2: 通知文言に「ピル」が直接含まれている

#### 症状

ロック画面・通知センターに「ピルの時間です」「今日のピルを忘れずに」等の文言が表示される。

| スヌーズ（one-shot） | ピルの時間です ⏰ | 毎日のルーティン ⏰ |
| アクションボタン | 今飲む | 記録する |

## 🆕 1行日記「今日のひとこと」機能の追加（午後）

### 背景・意思決定

「無料で十分か / 続けて使いたくなる要素が必要」という Tasuku の問題提起を受け、
**1行日記**を継続フックとして追加することを決定。あわせて Premium 設計を見直した。

**思想**: 「制限の解除」型ペイウォール（履歴を見せない＝罰）は動機として弱い。
日記を書く小さな習慣が「アプリを開く理由」と「やめたくない（スイッチングコスト）」を生む。
→ **日記を書く体験は無料、蓄積した記録から学ぶ体験（グラフ・全期間）を Premium** にする。

### 無料 / Premium の境界

| 機能 | 無料 | Premium |
|------|:---:|:---:|
| 1行日記を書く・編集 | ✅ | ✅ |
| 過去7日間の履歴・日記の閲覧 | ✅ | ✅ |
| 7日以上前の履歴・日記の閲覧 | ❌ ペイウォール | ✅ |
| 気分 × 服薬率のトレンドグラフ | ❌（Phase 2） | ✅（Phase 2） |

履歴画面の案内も「**Free版の制限**（罰）」→「**Premiumでできること**（価値）」に変更。

### 実装内容

**データ層**:
- `daily_notes` テーブルを新設（schema v2、マイグレーション `0002`）。1日1件（`date` UNIQUE）。
- `mood`（気分 1-5）カラムを**将来のグラフ用に先行確保**。UIには今は出さない（機能過多で
  UXを落とさない判断）。後でグラフを足すとき再マイグレーション不要。
- `upsertDailyNote()` は空メモなら行を残さず削除（DBを汚さない）。
- 既存ユーザー（Build 14, schema v1）は**次回起動時に 0002 が自動適用**される。

**Premium 判定の集約**:
- `lib/premium.ts` を新設し、`usePremium()` / `isWithinFreeWindow()` を一箇所に集約。
- RevenueCat 未実装のため `isPremium` は**常に false**。Phase 2 ではこの 1 ファイルだけ
  差し替えれば全画面のゲートが連動する（各画面に課金ロジックを散らさない）。
- `FREE_HISTORY_DAYS = 7` を定数化。

**UI 統合（2箇所）**:
- **ホーム画面**: 服薬カードの下に「今日のひとこと」入力欄。保存ボタンなし、
  フォーカスを外すと自動保存（画面離脱時も `flush` で取りこぼし防止）。
- **カレンダー詳細モーダル**: 日付ごとにメモを表示・編集。7日以上前は鍵アイコン＋
  ペイウォール誘導。`KeyboardAvoidingView` でキーボードがメモ欄を隠さないよう対応。
  日付切り替え時は `key={date}` で確実に再マウント＆保存。

## 🆕 追加バグ修正（夕方）

### Bug 3: カレンダーで 7 日以上前のステータス（✓/✗）が Free 版でも見えていた

#### 症状

月ナビゲーションは 7 日ゲートで制御されていたが、部分的に閲覧可能な月内の古い日付（例: 6月4日のとき 5月1〜27日）の服薬ステータスアイコンが Free 版でもすべて表示されていた。

#### 根本原因

`CalendarGrid` に Premium ゲートが存在せず、月単位の制御しかなかった。
仕様書（`01_pilllog.md:999`）では「7 日以上前を見ようとするとペイウォール表示（Free）」と規定されており、日付単位のマスクが必要だった。

#### 修正内容

- `CalendarGrid` に `isDateLocked?: (date: Date) => boolean` prop を追加。
- ロック対象の日付は🔒アイコン（10px）＋グレー日付番号で表示。タップ時はモーダルが開き、詳細の代わりにペイウォール誘導が表示される。
- `history.tsx` から `isDateLocked={isPremium ? undefined : (date) => !isWithinFreeWindow(date)}` を渡す。

**変更ファイル**:
- `components/domain/CalendarGrid.tsx` — `isDateLocked` prop 追加、ロック時の表示（🔒アイコン）実装
- `app/(tabs)/history.tsx` — `usePremium` を追加、`CalendarGrid` に `isDateLocked` を渡す

### Bug 4: 日記入力後にキーボードを閉じる手段がなかった

#### 症状

「今日のひとこと」入力欄をタップするとキーボードが表示されるが、閉じる方法がなかった（モーダルの × ボタンのみ）。保存されているかどうかも直感的にわからない。

#### 修正内容

`DailyNoteInput` の `TextInput` に以下を追加:

```tsx
returnKeyType="done"   // キーボード右下が「完了」キーになる
blurOnSubmit           // 「完了」を押すとキーボードが閉じる（multiline でも有効）
onSubmitEditing={handleBlur}  // 「完了」 = onBlur 扱いで即時保存
```

**変更ファイル**: `components/domain/DailyNoteInput.tsx`
