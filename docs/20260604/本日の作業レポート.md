### Bug 1: カレンダーで月をまたぐと誤ってペイウォールが発動する

#### 症状

- 今日が 6 月 3 日の場合、過去 7 日 = 5 月 27 日〜6 月 3 日が閲覧可能なはず
- 「前の月（5 月）」ボタンを押すと「7 日以上前の履歴を見るにはアップグレードが必要です」が表示され、5 月に戻れない

#### 根本原因

`history.tsx` の月移動ロジックで、移動先の月の「**開始日**」を 7 日前と比較していた。

```
// 修正前（誤り）
const newMonthStart = startOfMonth(newMonth);   // 5 月 → 5 月 1 日
if (isBefore(newMonthStart, sevenDaysAgo)) {   // 5/1 < 5/27 → ペイウォール発動 ❌
```

5 月 27〜31 日は 7 日以内に含まれるにもかかわらず、月の開始日（5/1）で判定していたため誤発動していた。

#### 修正内容

比較対象を月の開始日から**終了日**に変更。月内に 1 日でも 7 日以内の日付があれば閲覧を許可する。

```
// 修正後（正しい）
const newMonthEnd = endOfMonth(newMonth);       // 5 月 → 5 月 31 日
if (isBefore(newMonthEnd, sevenDaysAgo)) {      // 5/31 > 5/27 → 通過 ✅
```

**変更ファイル**: `app/(tabs)/history.tsx:108`

### Bug 2: 通知文言に「ピル」が直接含まれている

#### 症状

ロック画面・通知センターに「ピルの時間です」「今日のピルを忘れずに」等の文言が表示される。
他人に画面を見られた際にプライバシーが損なわれる。

#### 修正内容

全通知の文言から「ピル」を除去し、「ケア」「毎日のルーティン」などプライバシーに配慮した表現に統一した。

| 通知種別 | 修正前 | 修正後 |
|---------|--------|--------|
| pill-primary（服薬時刻） | 今日のピルを忘れずに | 今日のケア、忘れずに |
| pill-reminder（+N分後） | ピルの時間です ⏰ | 毎日のルーティン ⏰ |
| pill-evening（夜間確認） | 今日のピル、記録しましたか？🌙 | 今日のケア、記録しましたか？🌙 |
| pill-evening body | まだの方はタップして記録 | まだの方はタップして確認 |
| スヌーズ（one-shot） | ピルの時間です ⏰ | 毎日のルーティン ⏰ |
| アクションボタン | 今飲む | 記録する |

**変更ファイル**:
- `lib/notifications/setup.ts` — title / body 文言を変更（4 箇所）
- `lib/notifications/categories.ts` — アクションボタン「今飲む」→「記録する」
