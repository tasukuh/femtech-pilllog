
## 💡 学んだこと・注意点

### 1. GitHub Pages の公開

**リポジトリを公開する際の注意点**:
- セキュリティチェックが重要（API キー、秘密情報）

**無料で使える条件**:
- パブリックリポジトリのみ
- プライベートリポジトリは GitHub Enterprise（有料）が必要

---

### 2. 料金体系の設計

**買い切り vs サブスクリプション**:

| 項目 | 買い切り | サブスク |
|------|---------|---------|
| **ユーザー** | シンプル、心理的ハードル低 | 月額負担、解約の手間 |
| **開発者** | 管理が楽 | 継続的収益 |
| **適合性** | シンプルなアプリ、サーバーコストなし | 継続的なサービス、サーバーコストあり |

**このプロジェクトの結論**:
- 完全ローカルアプリ → サーバーコストなし
- AI機能なし → 継続コストなし
- シンプルさが売り → 買い切りが最適

---

### 3. スクリーンショットの管理

**App Store の要件**:
- 6.7インチ (1290 x 2796): 必須
- 6.5インチ (1242 x 2688): 推奨
- 5〜10枚

**Git に含めない理由**:
- UI を更新するたびに撮り直しが必要
- バイナリファイルは差分管理に向いていない
- リポジトリサイズが大きくなる
- App Store Connect で直接アップロード
