**記録するイベント**:

| イベント名 | タイミング | プロパティ |
|-----------|----------|----------|
| `app_opened` | アプリ起動時 | なし |
| `dose_recorded` | 服薬記録時 | `source: 'button' | 'notification'` |
| `history_viewed` | 履歴画面表示時 | なし |
| `notification_received` | 通知受信時 | `reminder_number: 1 | 2 | 3` |
| `premium_viewed` | ペイウォール表示時 | なし |
| `premium_purchased` | Premium 購入時 | `price: 980` |

## 🐛 トラブルシューティング

### 問題1: EAS Build が失敗する

**確認事項**:
1. `eas.json` の `production` プロファイルが正しいか
2. Apple Developer アカウントが有効か
3. Bundle ID が正しいか（`jp.tasuku.pilllog`）

**解決策**:
```bash
# ビルドログを確認
npx eas build:list
npx eas build:view <build-id>

# 再度ビルド
npx eas build --platform ios --profile production --clear-cache
```

---

### 問題2: TestFlight にアップロードされない

**確認事項**:
1. EAS Build が完了しているか
2. App Store Connect でアプリが登録されているか
3. Bundle ID が一致しているか

**解決策**:
```bash
# 手動でアップロード
npx eas submit --platform ios
```

---

### 問題3: TestFlight 審査に落ちる

**よくある理由**:
1. スクリーンショットが不足
2. プライバシーポリシーが不明確
3. 医療機器として誤解される表現

**解決策**:
- プライバシーポリシーを再確認
- 「医療アドバイスではない」を明示
- スクリーンショットを追加
