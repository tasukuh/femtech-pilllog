## 4. 説明文（4000文字以内）

```
■ ピルログとは

ピルログは、ピルの服薬記録を簡単に管理できるアプリです。

シンプルな操作で毎日の服薬を記録し、通知リマインダーで飲み忘れを防止。履歴カレンダーで服薬状況を一目で確認でき、あなたの健康管理をサポートします。


■ 主な機能

◆ ワンタップで服薬記録
ホーム画面のボタンをタップするだけで、今日の服薬を記録できます。ロック画面の通知からも直接記録可能なので、アプリを開く手間もありません。

◆ 段階的な通知リマインダー
設定した時刻に通知でお知らせ。飲み忘れた場合は、5分後、30分後に再通知します。忙しい毎日でも、飲み忘れを防止できます。

◆ 履歴カレンダーで一目確認
カレンダー形式で過去の服薬記録を表示。達成率も表示されるので、モチベーションアップにつながります。

◆ 完全プライベート
すべてのデータはあなたのデバイス内にのみ保存されます。サーバーに送信されることはないので、プライバシーも安心です。

◆ シンプルで使いやすい
複雑な機能は一切なし。「記録する」「確認する」だけのシンプル設計。誰でもすぐに使い始められます。


■ こんな方におすすめ

・ピルの飲み忘れが心配な方
・服薬記録を簡単に管理したい方
・プライバシーを重視する方
・シンプルで使いやすいアプリを探している方
・毎日の習慣を記録したい方


■ 使い方

1. オンボーディングでピル情報と服薬時刻を設定
2. 毎日、設定した時刻に通知が届く
3. ホーム画面のボタンをタップして記録
4. 履歴カレンダーで達成状況を確認

たったこれだけ。複雑な操作は一切ありません。


■ プライバシーへのこだわり

ピルログは、あなたのプライバシーを最優先に考えています。

・健康データはすべてデバイス内にのみ保存
・サーバーへの送信は一切なし
・個人を特定できる情報は収集しません
・位置情報やカメラへのアクセスは不要

詳しくは、プライバシーポリシーをご覧ください。
```
