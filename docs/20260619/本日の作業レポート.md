## 💡 学び・メモ

- **「価格は出るが購入は失敗」= 有料アプリ契約が未締結の典型症状**。製品情報の取得（getOfferings）と課金トランザクション（purchasePackage）は別物。
- **Sandbox テスターのメールは未登録アドレスが必須**（Gmail の `+` エイリアスが便利）。電話番号認証は Sandbox アカウント側の 2FA で、実電話番号を使ってOK・本物の Apple ID に影響しない。
- **DSA トレーダー申告は後から変更可能**。個人のうちは非トレーダー（EU非配信）で進め、法人化後に会社住所でトレーダー登録するのが安全。
- 個人 → 法人の切り替え：**銀行口座変更は容易**、ただし**アカウント種別変更**は D-U-N-S 取得 or App転送が必要（その時に対応）。
