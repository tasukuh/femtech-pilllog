### 🔴 優先度★★★【最優先】- 有料アプリ契約を「有効」にする

**これが完了しないと Sandbox でも本番でも一切課金できない。**

1. https://appstoreconnect.apple.com → **「ビジネス」**（Business）→ 契約
2. **有料アプリ契約**のステータスを確認 → 「保留 / 処理待ち」なら未完了項目を埋める
3. 必要な3点が全部 ✅ になると **「有効」** に変わる：

| 項目 | メモ |
|---|---|
| 連絡先情報 | 個人＝自分の情報でOK |
| **銀行口座** | 日本の銀行・**個人名義**（口座名義はアカウント種別と一致必須） |
| **税務フォーム** | W-8BEN（米国）で**日米租税条約を適用＝源泉徴収30%→0%**、日本の税務情報（マイナンバー=TIN） |

> ⚠️ **W-8BEN の租税条約 0% 申告を忘れない**（飛ばすと売上から30%引かれる）。
> ⚠️ 税務審査の反映に時間がかかることがある（即時〜数時間、稀に1日）。

**DSA（EU）トレーダー申告**: 前回**「非トレーダー / EU配信しない」を選択済み**。
将来 EU 配信する時（法人化後に会社住所で）トレーダーへ変更する。

## 💎 Phase 2 実装の設計（触る前に必読）

### Premium 判定は `lib/premium.ts` に集約
- `usePremium()` → `{ isPremium, isLoading }`。entitlement `'premium'` を参照
- `Purchases.configure()` は **`app/_layout.tsx` の `initialize()` で一度だけ**（`usePremium()` 内では呼ばない）
- iOS 以外 / 設定なしの環境では `isPremium = false` フォールバック
- API キー: `EXPO_PUBLIC_REVENUECAT_IOS_KEY`（`EXPO_PUBLIC_` 接頭辞必須）
- **QAバイパス**: `EXPO_PUBLIC_QA_PREMIUM=1` ビルド時のみ `isPremium=true`（`qa` プロファイル）

### HealthKit のデータフロー
```
HealthDashboard 表示
  → useQuery(['healthCorrelations', sheetId])
    → fetchCorrelationData()              [lib/health/queries.ts]
       → isCacheFresh()（24h TTL）          [lib/db/queries/healthSamples.ts]
          stale → syncSleepSamples() / syncRestingHeartRate()  [lib/health/sync.ts]
       → getHealthSamplesInRange() + getDoseRecordsInRange()
       → buildWeeklyCorrelations()         [lib/health/correlations.ts]（純粋関数）
          → WeekBucket[] → CorrelationChart（SVG）
```

### 制約・落とし穴
- **健康データは完全ローカル**（`health_samples` はキャッシュ、サーバー送信なし）
- 睡眠値は実睡眠のみ集計（`sync.ts` の `SLEEP_VALUES`、`inBed`/`awakeInBed` を除外）
- **オンボーディング中はペイウォール禁止**（タブ内からのみ到達）

## 🔧 トラブルシューティング

### 購入が「失敗しました」になる（← 今回の症状）
1. **有料アプリ契約が「有効」か**（最有力。「新規/保留」なら課金不可）
2. RevenueCat ダッシュボード → Customers で失敗トランザクションのエラー確認
3. Sandbox テスターでサインインしているか（設定 → Developer → Sandbox Account）
4. 課金製品 `jp.tasuku.pilllog.premium` のステータスが「提出準備完了」以上か

### ペイウォールの価格が空
1. Build 19 は RevenueCat キーが OTA 配信 → アプリ起動→数秒待つ→完全終了→再起動
2. RevenueCat の offering/製品と ASC 課金の紐付け
3. Sandbox サインイン

### HealthKit のグラフが空
1. **実機**か（Simulator 不可）
2. 端末ヘルスケアに睡眠・心拍データがあるか
3. read 権限を許可したか（拒否後は設定アプリから手動 ON）
