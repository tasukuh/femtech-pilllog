## 💎 設計リファレンス（触る前に確認）

### Premium 判定
- `usePremium()` → `{ isPremium, isLoading }` → `lib/premium.ts`
- entitlement: `'premium'` / QA バイパス: `EXPO_PUBLIC_QA_PREMIUM=1`
- `Purchases.configure()` は `app/_layout.tsx` の `initialize()` で 1 回のみ

### HealthKit データフロー
```
HealthDashboard
  → useQuery(['healthCorrelations', sheetId])
    → fetchCorrelationData()              [lib/health/queries.ts]
       → isCacheFresh()（24h TTL）
          stale → syncSleepSamples() / syncRestingHeartRate()  [lib/health/sync.ts]
       → buildWeeklyCorrelations()        [lib/health/correlations.ts]
          → WeekBucket[] → CorrelationChart（SVG）
```

### HealthKit 権限の永続化
- HealthKit の read 権限は「許可/拒否」をアプリから判定不可（iOS プライバシー設計）
- `HEALTH_CONNECTED_KEY = 'health_connected'` を `app_settings` に保存して判定
- 既に接続済みなら `requestAuthorization` を再実行（ダイアログは出ないが権限は維持）

### API キー
- `EXPO_PUBLIC_REVENUECAT_IOS_KEY`: `eas.json` env + EAS サーバー環境変数の両方に設定済み
- OTA 時は EAS サーバー環境変数のみ参照（`eas.json env` は OTA に影響しない）
