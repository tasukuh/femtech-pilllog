### Bug 1: 服薬後もリマインダーが届く

#### 症状

- 服薬時刻の通知から「今飲む」を押して記録した
- その後、+5分・+30分のリマインダー通知が来た

#### 根本原因

3層の問題が重なっていた:

| 問題 | ファイル | 詳細 |
|------|---------|------|
| スタブ呼び出し | `lib/db/queries/doseRecords.ts:11` | `cancelScheduledNotificationsForDose` をスタブ(`lib/db/notifications.ts`)からインポートしており、関数の中身が `console.log` だけで何もしていなかった |
| CALENDAR通知はキャンセル不可 | `lib/notifications/setup.ts` | 通知がCALENDER repeats:true設計なので doseRecordId ではキャンセルできない |
| 起動時の再スケジュール条件が不十分 | `lib/notifications/setup.ts:233` | `areDailyRemindersScheduled()` が `PILL_PRIMARY` の有無しか確認しておらず、フォローアップ通知が消えても「スケジュール済み」と判定されていた |

#### 修正内容

**`lib/notifications/setup.ts`**:
- `cancelFollowUpReminders()` を新規追加: `PILL_REMINDER_1`, `PILL_REMINDER_2`, `PILL_EVENING` をキャンセル（`PILL_PRIMARY` は残す）
- `areDailyRemindersScheduled()` を更新: `PILL_REMINDER_1` の存在も確認するように変更 → 次回アプリ起動時に全通知が自動再スケジュールされる

**`lib/notifications/index.ts`**:
- `cancelFollowUpReminders` をエクスポートに追加

**`lib/db/queries/doseRecords.ts`**:
- インポート先をスタブ(`'../notifications'`)から実装(`'../../notifications'`)に変更
- `markDoseAsTaken()` と `markDoseAsSkipped()` で `cancelFollowUpReminders()` を呼ぶように修正

#### 動作の流れ（修正後）

```
服薬記録 → cancelFollowUpReminders() 呼び出し
          → PILL_REMINDER_1/2/EVENING をキャンセル
          → 翌日アプリ起動時に areDailyRemindersScheduled() が false を返す
          → scheduleDailyReminders() で全通知を再スケジュール
```

#### 残制限（既知）

`TAKE_NOW` アクションボタンは `opensAppToForeground: false` のため、バックグラウンドで処理される。`cancelFollowUpReminders()` が呼ばれる前に OS がすでに `PILL_REMINDER_1`（+5分）を配信済みの場合、今日分は防げない。

- フォアグラウンド時: `configureForegroundNotificationBehavior()` の抑制ロジックで対処済み
- バックグラウンドで +5分以内: iOS の仕様上 Notification Service Extension なしでは防止不可

実用上の影響は「服薬から5分以内に1回だけ余計な通知が来る可能性がある」程度に限定された。

### Bug 2: シート進捗カウントが1日ずれる

#### 症状

- 5日目（4錠飲み終わった状態）で「4/4=100%」と表示される
- 5錠目を飲んでも進捗が正しく更新されない

#### 根本原因

`app/(tabs)/index.tsx:68` の計算式:

```typescript
// Before（バグあり）
const current = takenCount + 1; // 服薬済み4日 → current=5 → 5/5=100% になってしまう
```

`takenCount + 1` は「次に飲む日」を計算する式だが、リングの進捗表示に使うと1日分先行する。4錠飲んだ時点で「5/5=100%」と表示されてしまい、5錠目を飲む前にリングが満タンになる。

#### 修正内容

**`app/(tabs)/index.tsx`**:

```typescript
// After（修正後）
const current = takenCount; // 服薬済み日数をそのまま使う
// ...
const untilBreak = Math.max(0, pattern.active - current); // 式も1項削除（結果は同じ）
```

| 状態 | 修正前 | 修正後 |
|------|--------|--------|
| 4錠飲んだ | 5/5 = 100% ❌ | 4/5 = 80% ✅ |
| 5錠目を飲んだ | 6/5 = オーバー ❌ | 5/5 = 100% ✅ |
| 初日（未服薬）| 1/28 = 3.5% ❌ | 0/28 = 0% ✅ |

`daysUntilBreak` の計算は:
- 修正前: `active - (takenCount + 1) + 1 = active - takenCount`
- 修正後: `active - takenCount`

数学的に同値なので、**休薬期間までの日数表示は変わらない**。
