## 🔧 トラブルシューティング

### submit が「buildNumber 衝突」で失敗する

```
Build number X for app version 1.0.0 has already been used.
```

→ `eas build:version:set --platform ios` で現在値より大きい数字にセット

### 通知が実機で来ない

1. iOS 設定 → 通知 → ピルログ: すべて ON か？
2. 集中モード: ピルログが許可されているか？
3. アプリ起動ログに「Daily reminders missing — rescheduling」が出るか？
4. アプリの「すべてのデータを削除」→ 再オンボーディングで再現確認

### 次回ビルド手順（参考）

```bash
# ビルド実行
eas build --platform ios --profile production --non-interactive

# submit
eas submit --platform ios --latest --non-interactive
```
