## 💎 Phase 2 実装の設計（次回触る前に必読）

### Premium 判定は `lib/premium.ts` に集約（RevenueCat 結線済み）

- `usePremium()` → `{ isPremium, isLoading }`。entitlement `'premium'` を参照。
- `Purchases.configure()` は **`app/_layout.tsx` の `initialize()` で一度だけ**。
  `usePremium()` 内では呼ばない。
- iOS 以外 / 設定なしの環境では `isPremium = false` にフォールバック。
- API キー: `EXPO_PUBLIC_REVENUECAT_IOS_KEY`（`EXPO_PUBLIC_` 接頭辞必須）。

### HealthKit のデータフロー

```
[読み取り]
HealthDashboard 表示
  → useQuery(['healthCorrelations', sheetId])
    → fetchCorrelationData()           [lib/health/queries.ts]
       → isCacheFresh()（24h TTL）       [lib/db/queries/healthSamples.ts]
          stale → syncSleepSamples() / syncRestingHeartRate()  [lib/health/sync.ts]
                    → AppleHealthKit.getSleepSamples / getRestingHeartRateSamples
                    → upsertHealthSamples() → SQLite
       → getHealthSamplesInRange() + getDoseRecordsInRange()
       → buildWeeklyCorrelations()      [lib/health/correlations.ts]（純粋関数）
          → WeekBucket[] → CorrelationChart（SVG）
```

### 重要な制約・落とし穴

- **実機必須**: HealthKit は Simulator 非対応。`react-native-health` はネイティブモジュール
  → Expo Go 不可、EAS Development Build が必要。
- **睡眠値のフィルタ**: `getSleepSamples` は `inBed`/`awakeInBed` も返す。
  実睡眠のみ（iOS16+ の `asleepCore/Deep/REM` と legacy `asleep`）を集計している
  （`sync.ts` の `SLEEP_VALUES`）。
- **健康データは完全ローカル**: `health_samples` はキャッシュであり、サーバー送信は一切なし。
- **オンボーディング中はペイウォール禁止**（CLAUDE.md）。ペイウォールはタブ内からのみ到達可能
  なので自然に満たされている。

### health_samples テーブル（schema v3 / マイグレーション 0003）

- `sample_type`: `'sleep'`（分）| `'resting_hr'`（BPM）
- `date`: 'yyyy-MM-dd'、`value`: 整数、`fetched_at`: キャッシュ無効化用（24h TTL）
- クエリ: `lib/db/queries/healthSamples.ts`（期間取得・upsert・鮮度・剪定）

## 🔧 トラブルシューティング

### ペイウォールの価格が出ない / 空
1. `EXPO_PUBLIC_REVENUECAT_IOS_KEY` が EAS Secret に設定されているか。
2. RevenueCat ダッシュボードで offering / 製品が作成され、ASC の課金と紐付いているか。
3. Sandbox テスターアカウントでサインインしているか。

### HealthKit のグラフが空 / 折れ線が出ない
1. **実機**で動かしているか（Simulator は HealthKit 非対応）。
2. 端末の Apple ヘルスケアに睡眠・心拍データが存在するか。
3. 権限ダイアログで read を許可したか（拒否後は設定アプリから手動 ON が必要）。

### `react-native-health` でビルドが失敗
1. `app.json` の `plugins` に `["react-native-health", { "isClinicalDataEnabled": false }]` があるか。
2. iOS `entitlements` に `com.apple.developer.healthkit: true` があるか。
3. Apple Developer Portal で HealthKit capability が有効か。
