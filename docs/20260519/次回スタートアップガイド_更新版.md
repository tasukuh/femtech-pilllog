### 問題1: 通知が届かない

**確認事項**:
1. iOS設定 → ピルログ → 通知がONか
2. デベロッパーモードがONか
3. 通知時刻が正しく設定されているか

**解決策**:
```bash
# ログで確認
# [Notifications] Setup X gradual reminders のXが3であるか確認
```

---

### 問題2: アプリが起動しない

**解決策**:
```bash
# キャッシュをクリア
npx expo start --dev-client --clear

# または新しいビルドを作成
npx eas build --platform ios --profile development
```

---

### 問題3: データベースエラー

**解決策**:
1. アプリをアンインストール
2. 再インストール
3. オンボーディングを再実行
