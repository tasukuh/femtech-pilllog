## 🎯 次回やるべきこと（優先度順）

### 🔴 優先度高: 実機での通知テスト

**理由**: シミュレータでは通知機能の完全なテストができない

#### 事前準備: Development Build 作成

```bash
# EAS CLI がインストールされていない場合
npm install -g eas-cli

# Expo アカウントでログイン
eas login

# Development Build を作成
npx eas build --profile development --platform ios
```

**ビルド時間**: 約10〜20分

#### 実機にインストール

1. EAS Build からダウンロード
2. TestFlight 経由でインストール
3. または、直接 `.ipa` ファイルをインストール

#### テスト項目

1. **通知許可リクエスト**
   - オンボーディング最終画面で許可
   - iOS設定で通知がONになっているか確認

2. **通知スケジュール**
   - ピル服薬時刻を「現在時刻 + 2分」に設定
   - 2分後に通知が届くか確認
   - 通知内容: "おはようございます ☀️ 今日のピルを忘れずに"

3. **ロック画面アクション**
   - 通知を長押し or 下にスワイプ
   - 「今飲む」アクションをタップ
   - → アプリ内のDBが更新されるか確認

4. **段階的リマインダー**
   - 未記録のまま30分経過 → 2回目の通知
   - 未記録のまま60分経過 → 3回目の通知

**想定される問題と対処法**:
- 通知が届かない → `expo-notifications` の設定確認
- アクションが動作しない → `lib/notifications/categories.ts` のカテゴリ登録確認
- 通知音が鳴らない → iOS設定で音量確認

## 🔧 トラブルシューティング

### 問題1: アプリが起動しない

**症状**: メトロバンドラーは起動するが、シミュレータでエラー

**解決策**:
```bash
# キャッシュをクリア
npx expo start --clear

# または node_modules を再インストール
rm -rf node_modules
npm install
```

---

### 問題2: データベースエラー

**症状**: `no such table` エラー

**解決策**:
1. アプリをアンインストール
   ```bash
   xcrun simctl uninstall booted app.pilllog.tasukuh
   ```
2. アプリを再起動
3. マイグレーションログを確認

---

### 問題3: 進捗が更新されない

**症状**: 履歴画面で記録を変更しても、ホーム画面の進捗が変わらない

**解決策**:
- Pull-to-refresh（画面を下にスワイプ）
- または、アプリをリロード（メトロバンドラーで `r` キー）

**確認**: 
- `lib/queries/hooks.ts` で `refetchType: 'active'` が設定されているか
- `app/(tabs)/index.tsx` で `allRecords` が依存配列に含まれているか

---

### 問題4: 未来の日付が記録できてしまう

**症状**: 未来の日付で「服薬済みにする」ボタンが表示される

**解決策**:
- 最新のコードでは修正済み
- `app/(tabs)/history.tsx` で日付チェックが実装されている
- 誤って記録した場合は「設定 → 未来のデータをクリア」を実行

## 📞 サポート情報

### よくある質問

**Q: オンボーディングをスキップしてホーム画面から始めたい**  
A: シミュレータを一度アンインストールすると初回起動になります。

**Q: データベースの中身を確認したい**  
A: 以下のツールを使用:
- [Flipper](https://fbflipper.com/) + SQLite プラグイン
- または、`lib/db/queries/` に直接クエリを追加してログ出力

**Q: 通知が届かない（シミュレータ）**  
A: シミュレータでは通知機能が制限されています。実機でテストしてください。
