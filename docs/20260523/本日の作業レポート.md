#### 6. バグ修正（データ削除機能）

**問題**:
「すべてのデータを削除」を実行すると、「エラー：データの削除に失敗しました」と表示される

**原因**:
```typescript
// 変更前
sqlite.execSync(`DROP TABLE IF EXISTS ${table}`);  // テーブルごと削除
```

テーブルを削除した後、`setOnboardingStatus(false)` を呼び出すと、テーブルが存在しないためエラーになっていた。

**修正内容**:
```typescript
// 変更後
sqlite.execSync(`DELETE FROM ${table}`);  // データのみ削除、テーブル構造は保持
```

**コミット**:
```
fix: データ削除機能のバグを修正

- DROP TABLE → DELETE FROM に変更
- テーブル構造を保持することで、後続処理のエラーを防止
```

**所要時間**: 約30分

### 3. データ削除機能のバグ

**原因**:
- `DROP TABLE` を使用していたため、テーブル構造が削除された
- 後続処理で INSERT しようとするとエラー

- DROP TABLE は、マイグレーションやテスト環境でのみ使用

### 2. EAS Build と Submit

**Build コマンド**:
```bash
eas build --platform ios --profile production
```

**Submit コマンド**:
```bash
eas submit --platform ios --latest
```

**注意点**:
- 対話形式のプロンプトがあるため、バックグラウンド実行できない
- Apple ID 認証が必要
- App Store Connect API キーを生成すると、次回から自動化できる

### 3. データベースのリセット処理

**ベストプラクティス**:
- テーブル構造は保持したまま、データのみ削除する
- `DROP TABLE` ではなく `DELETE FROM` を使用
- テーブルの再作成が必要な場合は、マイグレーションを実行
