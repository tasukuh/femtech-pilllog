### 🟢 優先度★ - PostHog 統合

**推定時間**: 2〜3時間

**目的**: 匿名化された使用統計の収集

**前提知識**:
- PostHog は、プライバシーに配慮した分析ツール
- ユーザーの行動（イベント）を記録
- 健康データの中身は送信しない（イベント名のみ）

**手順**:

#### 1. PostHog アカウント作成

1. https://posthog.com/ にアクセス
2. 「Get started - free」をクリック
3. アカウント登録（無料プランで開始）

#### 2. プロジェクト作成

1. プロジェクト名: 「ピルログ」
2. API キーを取得（後で使用）

#### 3. イベント設計

以下のイベントを記録する:

| イベント名 | タイミング | 目的 |
|-----------|----------|------|
| `app_opened` | アプリ起動時 | DAU（デイリーアクティブユーザー）を測定 |
| `onboarding_started` | オンボーディング開始 | ユーザーの離脱率を測定 |
| `onboarding_completed` | オンボーディング完了 | 完了率を測定 |
| `dose_recorded` | 服薬記録時 | 機能の使用頻度を測定 |
| `history_viewed` | 履歴表示時 | 機能の使用頻度を測定 |
| `notification_received` | 通知受信時 | 通知の効果を測定 |
| `premium_viewed` | Premium 画面表示 | 課金への導線を測定 |
| `premium_purchased` | Premium 購入完了 | コンバージョン率を測定 |

**重要**: 健康データの中身（ピル名、服薬時刻、記録内容など）は送信しない

#### 4. SDK インストール

```bash
expo install posthog-react-native expo-file-system expo-application expo-device expo-localization
```

#### 5. 初期化コード

`app/_layout.tsx` に追加:

```typescript
import PostHog from 'posthog-react-native';

// PostHog 初期化
PostHog.setup('YOUR_API_KEY', {
  host: 'https://app.posthog.com',
  enableSessionReplay: false, // プライバシー保護のため無効
});
```

#### 6. イベント送信コード

例（服薬記録時）:

```typescript
import PostHog from 'posthog-react-native';

// 服薬記録時
PostHog.capture('dose_recorded');
```
